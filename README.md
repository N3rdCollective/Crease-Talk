# CreaseTalk

Media + artist discovery platform UI built from the CreaseTalk design brief and homepage mockup.

## Stack

- React + Vite
- Tailwind CSS
- HTML5 media player
- Supabase-ready component structure (content currently mocked in `src/data/content.ts`)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
